# Context OS — Kit de arranque

> Context OS es el **método interno** para convertir caos en dirección. No es (todavía) el nombre del producto.
> El negocio real de los próximos 90 días: un **servicio productizado** que captura el conocimiento tácito de clínicas pequeñas y lo convierte en un sistema vivo con IA.

---

## La apuesta en una línea

**Conseguir 3 clientes pagados, en un solo vertical (clínicas de fisio/salud en Córdoba), en 90 días.** El producto se destila de lo que se repita — no se inventa antes de tener clientes.

**Una sola métrica:** euros facturados del vertical. Todo lo demás es secundario.

## Plan de los próximos 7 días

1. **Día 1** — Confirmar vertical (clínicas, salvo que tu red caliente diga otro). Decisión cerrada 90 días.
2. **Día 2** — Personalizar la oferta de 1 página con tus datos y precio.
3. **Día 3** — Tener listas las 3 plantillas (ya están; adáptalas a tu voz).
4. **Día 4** — Montar el caso #0 (demo).
5. **Día 5** — Lista de 15 clínicas reales + elegir mensaje.
6. **Día 6** — Contactar a las 15.
7. **Día 7** — Primer diagnóstico real + entregar el mapa de 1 página. **Ya estás en el mercado.**

## Reglas para no dispersarte (las tuyas, recordadas)

- **No abrir universos nuevos** durante 90 días. Toda idea nueva va a un archivo de "después".
- **Villa, Plasmandoluz, fotografía, app: congelados como negocio.** Siguen vivos como motor/marketing, no como caja.
- **"Context OS" es nombre interno.** Hacia fuera vendes resultado, no "contexto".
- **El servicio se hace a mano primero.** Si no se vende a mano, el SaaS habría fracasado igual.
- **El riesgo nº1 no es el contenido: es no mandar los mensajes.** El siguiente paso es acción, no documento.
