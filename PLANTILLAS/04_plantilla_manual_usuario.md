# Plantilla del Manual de Usuario (informe)
### Producto "Manual de Usuario" — Identity Intelligence · versión 1

> **Qué es esto:** el molde rellenable del entregable. Sirve para producir el **caso 0** (Antonio) a mano y, después, como contrato de salida del pipeline automatizado.
> **Regla de oro:** ninguna afirmación fuerte entra sin evidencia citada. Si no hay rastro que lo respalde, es hipótesis — y se marca como tal.
> **Tres longitudes:** Corta (~10 pág.) = secciones 1, 2, 3, 8, 13, 14, 16, 18. Media (~50) = todo menos el detalle de las 50 miradas y anexos. Extrema (~100) = todo.
> **Nivel de evidencia (marcar en cada afirmación fuerte):** `[Observado]` (está literal en el material) · `[Inferido]` (deducido de varias señales) · `[Hipótesis]` (a explorar, con contraevidencia).
